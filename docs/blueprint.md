# **App Name**: BahujanSphere

## Core Features:

- Multilingual Event Display: Display a filterable list of events with multilingual support.
- Event Bookmarking: Allow users to save events as bookmarks for later access.
- Event Submission: Implement a form for users to submit events, which are then added to a moderation queue.
- Calendar View: Provide a calendar view to explore events by date.
- AI Tag Suggestion: Suggest relevant tags and categories to event submitters using a tool trained on existing event data.
- Language Switching: Enable users to switch between available languages.

## Style Guidelines:

- Primary color: Deep saffron (#FF9933), representing courage and sacrifice. 
- Background color: Pale yellow (#FAF0E6), a light, warm, inviting tone that is close in hue to the primary, but highly desaturated.
- Accent color: Ochre (#CC7722), which complements the primary color and offers contrast, while retaining a degree of earthiness and connection to the themes implied in the request.
- Font pairing: 'Literata' (serif) for headlines, offering a literary and slightly formal feel, paired with 'PT Sans' (sans-serif) for body text, providing a modern yet warm balance.
- Use clear, culturally relevant icons representing various event categories and tags.
- Typography-first design with clearly-segregated content blocks.
